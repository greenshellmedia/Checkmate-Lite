Qu’est-ce qu’une estimation de perfoumance sur un seul match ?

Il s’agit d’une estimation distincte basée sur les décisions notées dans un match, affichée avec une confiance d’échantillon faible, modérée ou foute. Ce n’est pas la note réelle Chess.com, FIDE ou over-the-board du joueur.
