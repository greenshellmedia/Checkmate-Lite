Ratings

A one-game performance estimate is not your Chess.com rating.

Keep these separate

Source rating versus estimated performance

The source rating comes from Chess.com or Lichess. CheckmateMore’s single-game estimate describes the rated decisions in that game and shows Low, Moderate, or Strong sample confidence. It is not a FIDE, over-the-board, or platform rating, and one game does not define a player.

Questions

Game analysis FAQ

Can CheckmateMore analyse Chess.com games?

Yes. Lite can review a Chess.com game in the browser. A free account can import Chess.com and Lichess games so they can be stored. Availability still depends on the game data.

What is a single-game performance estimate?

It is a separate estimate based on rated decisions in one game, shown with Low, Moderate, or Strong sample confidence. It is not the player’s real Chess.com, FIDE, or over-the-board rating.

Does a review promise a rating gain?

No. A review explains decisions in that game. It does not guarantee wins or a particular rating outcome.
