Von Fehlerbezeichnungen zu nützlichen Themen

"Blunder" beschreibt die Schwere der Figur. "Ignorierte einen gegnerischen Schlag nach zweimaliger Bewegung derselben Figur" beschreibt eine trainierbare Gewohnheit. Die Arbeit mit wiederkehrenden Mustern sollte vom ersten Label zur zweiten Erklärung wechseln.

Wann wird eine Gewohnheit korrigiert?

Nennen Sie eine Gewohnheit nicht nach einem guten Spiel fest. Vergleichen Sie eine spätere Stichprobe mit der früheren Basislinie und fordern Sie genügend berechtigte Gelegenheiten, bevor Sie die Verbesserung als dauerhaft präsentieren.

Probier das mal

Speichern Sie eine repräsentative Position, nennen Sie die Entscheidungsregel, die Sie sich merken möchten, und prüfen Sie, ob sie in Ihren nächsten passenden Spielen wieder vorkommt.
