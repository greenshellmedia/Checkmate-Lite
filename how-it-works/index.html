The coaching loop

From one reviewed game to proof that a habit changed.

Review or import a game, explain the critical moment, establish a baseline across repeated opportunities, train the pattern, then watch future games for evidence of transfer.

Create a free account Try the loop in Lite first

Four steps

Each step needs the one before it.

  1. 01

    Bring in a game

    Lite reviews one Chess.com game in the browser. A free account connects Chess.com and Lichess so eligible games can be stored.

  2. 02

    Explain the turning point

    Game analysis pairs the classification with evaluation, phase ratings, opening context, and a playable alternative.

  3. 03

    Wait for a repeating theme

    Weekly coaching only calls something a habit when enough stored games support it.

  4. 04

    Train, apply and prove

    Suitable misses return as personal practice and fresh Stockfish-validated variations. Improvement Proof then measures the same habit in future games.

Worked example

What the loop looks like on a real board.

Illustrative workflow

23…Qd6 hangs the queen to Nb5

The review does not stop at “Blunder, −2.4”. It names the hanging piece, shows 23…Qc7, and keeps the Najdorf context. If a second eligible game shows the same loose queen, Pro can set one weekly objective with a success condition. The capture then returns as a puzzle. This example is not a claim about a named player.

Limits

What this loop does not claim

Does CheckmateMore promise a rating gain?

No. It organises evidence and practice from your games. It does not guarantee wins or a particular rating outcome.

Does it replace a human coach?

No. A human coach can still add judgement, accountability, and broader teaching context.

Pro and Unlimited are in beta. Features and availability may evolve. The app shows current entitlements before you upgrade.
